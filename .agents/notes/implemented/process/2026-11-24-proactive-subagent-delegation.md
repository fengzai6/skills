# Agent Note: 全局规范主动分派子代理

Status: implemented

## Problem

主代理可能串行完成边界清楚、可以并行的子任务。只在 `dev-standards` 的重型任务流程中提到子代理编排，无法为其他任务提供开工时的分派判断。

## Decision

`rules/main.md` 的工具使用规范要求拆解任务时主动识别独立工作，在允许分派且并行有预期收益时尽早分派。主代理负责明确范围、推进手头工作并核验结果。任务依赖、写入冲突和工具可用性决定何时由主代理直接推进。

## Alternatives considered

- 将条目放在 `dev-standards` 的任务分流中，可以复用开发任务的分流入口，但该入口只覆盖开发任务。独立资料核查等非开发工作也符合相同的分派条件，因此规则放在全局入口。

## Consequences

- 开发和非开发任务共用一套分派条件，满足条件的子任务可以在主代理继续推进时启动。
- 主代理需要承担任务划分、上下文交接和结果核验的成本。只有预期能缩短交付时间或提高验证质量的独立工作才触发分派。
